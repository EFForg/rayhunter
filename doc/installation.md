# Installing Rayhunter

So, you've got one of the [supported devices](./supported-devices.md), and are ready to start catching IMSI catchers. You have three options for installing Rayhunter:

* [installing from a release GUI](./installing-from-release-gui.md)
* [installing from a release CLI](./installing-from-release-cli.md)
* [installing from source](./installing-from-source.md)

If you're unsure which to choose, we recommend [installing from a release GUI](./installing-from-release-gui.md).
